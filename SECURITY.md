# Security policy

This repository is a research artifact and must not contain live or demo credentials, account databases, runtime logs, server addresses, or deployable private configuration.

Please report a suspected secret or private-data disclosure privately to the repository owner instead of opening a public issue. Revoke or rotate any credential before discussing remediation. Historical backtest archives in releases have authentication fields blanked, but should still be treated as untrusted ZIP/serialization input and inspected only in a trusted environment.
